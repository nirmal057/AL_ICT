# Connect A/L ICT Mind Map with Theory Pages

I want to improve the complete Sinhala G.C.E. A/L ICT Mind Map in my "All bits of ICT" website.

The Mind Map should not be only a visual diagram.

I want every important Mind Map topic to be connected to the corresponding **Theory / Notes content** in the website.

## Main requirement

When a student clicks a topic/node in the Mind Map, it should navigate to the relevant A/L ICT Theory page.

Example:

* `දත්ත (Data)` → Data & Information Theory
* `තොරතුරු (Information)` → Data & Information Theory
* `CPU` → Computer / CPU Theory
* `Fetch–Decode–Execute Cycle` → CPU / Instruction Cycle Theory
* `Number Systems` → Data Representation Theory
* `Logic Gates` → Digital Circuits Theory
* `Karnaugh Map` → Digital Circuits / K-Map Theory
* `Operating System` → Operating System Theory
* `OSI Model` → Networking Theory
* `IP Address` → Networking Theory
* `ER Diagram` → Database Theory
* `SQL` → Database Theory
* `Algorithm` → Programming Theory
* `Python` → Programming Theory
* `HTML` → Web Development Theory
* `CSS` → Web Development Theory
* `JavaScript` → Web Development Theory
* `IoT` → Internet of Things Theory
* `E-Commerce` → ICT in Business Theory
* `Artificial Intelligence` → New Trends / Future ICT Theory

## IMPORTANT: Use the existing Theory content

## Clickable Mind Map

The Mind Map must support clickable topics.

If Mermaid's standard `mindmap` syntax does not support reliable clickable nodes in the current Mermaid configuration, do NOT force unsupported Mermaid syntax.

Instead, use the best reliable approach for this project, such as:

* a custom React mind-map node system,
* clickable overlay elements,
* a supported Mermaid click mechanism,
* or another existing project component.

The final result must actually work in the browser.

## Navigation behaviour

When a student clicks a topic:

1. Navigate to the matching Theory page.
2. Keep the existing website layout/navigation.
3. Do not open unnecessary new tabs.
4. Preserve browser back-button behaviour.
5. If a topic has no dedicated Theory page yet, make the node non-clickable or show a suitable "Theory coming soon" state rather than navigating to a broken URL.

## Topic-to-Theory mapping

Create a clear mapping object/data structure rather than hardcoding routes throughout the UI.

For example:


BUT use the actual routes already present in this project instead of these example URLs.

* Do not create overlapping clickable areas.
