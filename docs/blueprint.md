# **App Name**: ICTNote

## Core Features:

- Note Viewing: View notes saved as html or markdown as a book.
- A4 Page Formatting: Format notes to fit A4-sized pages for printing and on-screen view.
- Print Mode: Dedicated print mode to select and print specific content (notes, past papers, diagrams).
- Print-Ready View: Preview the document as it will appear when printed, ensuring proper formatting and allow to print or save as pdf
- Accessibility Features: Implement accessibility features for users with disabilities, such as screen reader compatibility and keyboard navigation.
- Different View Options: Offer various view options, such as full-screen mode, night mode, and focus mode, to enhance the user experience.
- Content Search: Enable users to search for specific content within their notes.

## Style Guidelines:

- Primary color: Soft blue (#A7D1AB) to evoke a sense of calmness and focus, inspired by the traditional color of paper and notebooks.
- Background color: Light grey (#F0EBE3) to provide a comfortable contrast for reading and writing. Heavily desaturated blue to align to the primary.
- Accent color: Muted green (#77A658) for interactive elements, drawing from the natural and calming aspect of the primary, but adjusted for visibility and focus.
- Body font: 'Literata', a transitional serif, for body text.
- Headline font: 'PT Sans', a humanist sans-serif, for headlines.
- Simple, geometric icons to represent different functions and tools within the application.
- Clean and organized layout with a focus on readability and ease of navigation.
- Subtle animations to provide feedback on user interactions, such as page transitions and button presses.
